# КПлинк market-ready demo

Более сильная demo-версия MVP для GitHub + Vercel.

## Что внутри

- landing с оффером и секциями под рынок
- dashboard с активностью по КП
- страница пакетов
- сценарий создания КП
- публичная страница предложения
- тёмно-синий + мятный стиль

## Запуск локально

```bash
npm install
npm run dev
```

## Деплой

1. Загрузите распакованные файлы в корень GitHub-репозитория
2. Импортируйте репозиторий в Vercel
3. Framework Preset: Next.js
4. Root Directory: ./
